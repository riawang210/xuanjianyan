# 选检验 · 医学统计方法选择器

> 不教你学统计，只在你卡壳的那一秒告诉你：**这组数据该用哪个检验。**

一个面向医生和医学生的轻量工具：像做问诊一样回答几个问题，30 秒内给出推荐的统计检验方法，并附上 SPSS 操作路径、R 代码、结果书写方式和「为什么不是别的方法」的对照。

🔗 **在线体验**：https://riawang210.github.io/xuanjianyan/
📱 手机端优先设计 — 值夜班、通勤、改投稿前都能随手点开。

## 解决什么问题

医学科研里最高频的卡壳点，不是「不懂统计」，而是「**此刻这组数据该用哪个方法**」：

- 分类变量 → 卡方还是 Fisher 精确检验？
- 数据不正态 → t 检验还是 Mann-Whitney U？
- 三组以上 → ANOVA 还是 Kruskal-Wallis？

翻书、翻知乎要半小时，翻完还是不确定，生怕被导师一句「方法选错了」打回来。
「选检验」把这一秒的决策做成可执行的答案。

> 需求来源：「医生进化岛 · 面向医生和医学生」社区——爆款笔记（赞 1.8k / 藏 2.1k）、店铺后台咨询、以及搜索飙升词「统计方法 选择 小白 +280%」三处交叉验证。

## 核心功能

- 🩺 **问诊式决策树**：研究目的 → 结局类型 → 分组 → 设计 → 分布，逐步收敛
- ⚡ **18 种方法全覆盖**：t 检验、配对 t、Mann-Whitney U、Wilcoxon、单因素 ANOVA、重复测量 ANOVA、Kruskal-Wallis、Friedman、卡方、Fisher、McNemar、R×C 卡方、Pearson、Spearman、多重线性回归、Logistic 回归、Cox 回归 / KM+Log-rank
- 🖱️ **可执行结果**：每个结论附 SPSS 操作路径 + R 代码
- 📝 **结果怎么写**：给出论文中该报告的统计量格式
- ⚠️ **避坑提示 + 方法对照**：解释「为什么是它、不是另一个」，消除选错焦虑
- 🎬 **场景一键带入**：内置常见场景（如「小样本罕见病比较」），演示即点即得

## 技术说明

- 纯前端单文件（`index.html`），零依赖、无后端
- 决策逻辑为确定性的医学统计方法选择树，离线即可运行
- 部署在 GitHub Pages

> 本工具为统计方法**选型参考**，不替代专业统计学建议；最终方法的适用性请结合研究设计判断。
